# PowerShell-ScriptsBasicos
Repositorio para trabajos escolares

16/08/2025
Este repositorio contiene archivos que se van desarrollando durante el curso de una materia.
Contiene ejercicios que realizan trabajos de ciberseguridad basicos para auditar.
El Ejercicio 4 es para verifiacar los usuarios que no se hallan usado en mucho tiempo o que no hayan iniciado secion.
El Ejercicio 5 es para verificar que el archivo que utilizemos exista.
El Ejercicio 6 es una auditoria basica para los usuarios y los servicios.

Al desarrollar esto aprendi que algo tan minimo como verificar los usuarios pueda detectar algun malware en el equipo.
